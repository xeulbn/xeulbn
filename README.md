# About Me

### 사용자의 불편에서 시작하여 더 나은 방향을 고민합니다.

만든 기능이 실제로 어떻게 쓰이는지에 관심이 많습니다.
사용자의 관점에서 회고합니다.
사용자의 피드백을 듣고, 처음의 가정이 맞았는지 회고합니다.  
필요하다면 방향을 바꾸면서 서비스에 필요한 것을 찾아갑니다.

### 회고를 좋아합니다.

실패 속에서 무엇을 배우고, 무엇을 얻었는지 회고하는 것을 좋아합니다. 
다양하게 시도하고 실패하며 살고 있고 그 안에서의 배움을 통한 성장의 기반이 되는 회고를 좋아합니다.

### 배운 것을 나누며 더 깊이 이해합니다

직접 겪은 문제를 다른 사람에게 설명하는 걸 좋아합니다.
어디에서 막혔고 어떤 단서로 풀었는지 이야기하다 보면, 안다고 생각했던 부분에서도 막힐 때가 있습니다.
그때 받은 질문은 제가 다음에 공부할 주제가 되기도 합니다.

## 요즘 학습하는 것
- **오브젝트** — 객체 지향 설계
- **Spring의 동작 원리** — 빈 생명주기, 프록시와 AOP, 트랜잭션 경계
- **AI의 활용** — 개발을 하며 Loop Engineering을 실험하고 테스트를 실행해 결과를 AI에 전달하는 Harness를 만들고 있습니다.

## 요즘 만드는 것

### 디톡스메이트 · [detoxmate-be](https://github.com/DDD-Community/detox.mate-be.git)

알림 도메인을 맡아 개발하였으며, 사용자의 피드백을 기반으로 디벨롭과 피벗을 반복해나가고 있습니다.
